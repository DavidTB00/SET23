# Installasjon
1. Pass på at du har Node.js installert. (Kan sjekkes ved å åpne PowerShell eller terminal og skrive inn: 'node -v')
2. Windows brukere må kjøre følgende i PowerShell for å kunne installere node.js React: 'Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned'
3. Åpne integrated terminal i VS Code og skriv følgende: 'npm install'
# Kjøring
1. Åpne integrated terminal i VS Code og skriv følgende: 'npm run dev'
2. Du vil få en lenke i terminalen som er f.eks 'http://localhost:5173/' legg denne i nettleseren din.
